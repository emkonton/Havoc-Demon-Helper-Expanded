# Havoc Demon - Расширенная документация команд (Русский)

Ссылка на оригинальный проект: [https://github.com/havocframework/havoc](https://github.com/havocframework/havoc)

---

*(Примечание: Здесь переведены основные модули. Полный синтаксис соответствует английской/турецкой версиям.)*

### help
Показывает справочное сообщение указанной команды.
**Использование:** `help [команда]`
Выводит внутрисистемную справку и сведения об использовании любой команды или модуля. Без параметров возвращает список всех команд.
**Примеры:**
- `help`
- `help token`

### sleep
Задает задержку сна и джиттер (разброс).
**Использование:** `sleep [задержка] (джиттер)`
Определяет интервал связи (check-in) Demon с сервером (Teamserver). Параметр «джиттер» указывается в процентах и помогает скрыть активность от систем безопасности.
**Примеры:**
- `sleep 10`
- `sleep 60 15`

### proc list
Отображает список запущенных процессов на целевой машине.
**Использование:** `proc list`
Подробно перечисляет активные в настоящее время процессы (Идентификатор процесса, имя, архитектура и т.д.).
**Примеры:**
- `proc list`

### shell
Выполняет команды cmd.exe и получает вывод.
**Использование:** `shell [команды]`
Выполняет команды с помощью командной строки Windows (cmd.exe). Вывод направляется непосредственно оператору.
**Примеры:**
- `shell dir c:\windows\system32`

### token steal
Крадет токен из указанного процесса.
**Использование:** `token steal [pid] (дескриптор)`
Перехватывает токен высокопривилегированного процесса и сохраняет его в хранилище учетных данных для дальнейшего использования.
**Примеры:**
- `token steal 1337`
